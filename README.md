# GamersVoice

A lightweight, native Android in-game voice chat application and companion WebRTC signaling server.

## Features
- **Ultra Lightweight:** Native Android Views (No Compose/Flutter overhead) for <8MB APK and <120MB RAM usage during gameplay.
- **Low Latency:** WebRTC peer-to-peer audio streams for up to 5 players per room.
- **Signaling Server:** Node.js WebSocket signaling server ready for Render.com free tier hosting.
